## Report a bug

<Steps>

### Upgrade first

Run the latest version. Your bug may already be fixed.

```bash
pnpm add -D @pandacss/dev@latest
```

### Search existing issues

Check [open issues](https://github.com/chakra-ui/panda/issues) before opening a new one. If you find yours, add your
case to it rather than opening a duplicate — more real examples help us fix it faster.

### Build a minimal reproduction

Strip your project down to the smallest thing that still shows the bug. Most of the time this is a `panda.config.ts`,
one component, and the CSS Panda emitted. A reproduction is the difference between a fix this week and a fix whenever.

### Open the issue

Include your Panda version (`panda --version`), your bundler, and what you expected versus what you got.

[Open a bug report →](https://github.com/chakra-ui/panda/issues/new/choose)

</Steps>

## Request a feature

Feature ideas go to [Discussions](https://github.com/chakra-ui/panda/discussions), not issues. Say what you're trying to
do, not just the API you want — the underlying problem is usually the useful part, and there's often a way to do it
today.

Vote on what's already proposed in the [roadmap](https://panda-css.canny.io/).

## The docs are wrong

Every page has an **Edit this page** link at the bottom. That's the fastest path: it opens the file on GitHub and you
can fix a typo without cloning anything.

For something bigger — a page that's confusing, a missing guide, an example that doesn't work — open a discussion and
tell us what you were trying to learn.

## Report a security issue

Don't open a public issue. Email the maintainers or use GitHub's
[private vulnerability reporting](https://github.com/chakra-ui/panda/security).
