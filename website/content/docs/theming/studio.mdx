Panda writes your design system to `styled-system/specs/tokens.json`. Render it however you like — a page, a Storybook
story, an MDX doc. Panda hands you the data; the design is yours.

## Tokens as data

`panda codegen` writes `styled-system/specs/tokens.json` — tokens grouped by category, values resolved:

```json
{ "data": [{ "type": "colors", "values": [{ "name": "red.500", "value": "#ef4444" }] }] }
```

## A color grid

```tsx
import { grid } from 'styled-system/patterns'
import tokens from 'styled-system/specs/tokens.json'

export function Colors() {
  const colors = tokens.data.find(group => group.type === 'colors')

  return (
    <div className={grid({ columns: 3, gap: '4', padding: '6' })}>
      {colors?.values.map(color => (
        <div key={color.name}>
          <div style={{ background: color.value, height: 64, borderRadius: 8 }} />
          <p>{color.name}</p>
          <p>{color.value}</p>
        </div>
      ))}
    </div>
  )
}
```

Every category shares the `{ name, value }` shape — swap `'colors'` for `'spacing'`, `'fonts'`, or `'radii'`. See
[JSON Spec](/docs/theming/json-spec) for the full file.

## Or use the viewer

Don't want to build one? [panda-spec-studio](https://github.com/Adebesin-Cell/panda-spec-studio) is a ready-made
viewer — drop your `tokens.json` or paste it, and every category renders with search and light/dark. No install.
