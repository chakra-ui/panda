# Panda Studio

`panda studio` turns your resolved design tokens into two things you can build on: **data** and **HTML**. The API is
inspired by [Tiptap](https://tiptap.dev)'s `getHTML` / `getJSON` — Panda ships the content, you own the presentation.

```bash
panda studio
```

This emits `styled-system/studio` and boots a live viewer at `http://localhost:4000` (set `--port` to change it).
Re-run after a config change to refresh.

## The two functions

`styled-system/studio` exports two framework-agnostic functions:

```ts
import { getTokenJson, getTokenHtml } from '../styled-system/studio'
```

### `getTokenJson`

Returns your tokens as data. Filter by `category`, search with `query`, or omit both for everything.

```ts
getTokenJson({ category: 'colors' })
getTokenJson({ category: 'spacing', query: 'sm' })
getTokenJson() // all tokens
```

Each token is `{ category, path, name, value, conditions? }`. Semantic tokens include a `conditions` map of their
resolved per-condition and per-theme values. Walk the result to build whatever UI you want.

### `getTokenHtml`

Returns semantic, **style-free** HTML — names and values as text, everything else as `data-*` attributes. It ships no
CSS, so you style it however you like.

```ts
getTokenHtml({ tokens: getTokenJson({ category: 'colors' }) })
getTokenHtml({ category: 'colors', query: 'brand' }) // filter inline
```

Drop the string into any framework:

```tsx
// React
function Colors() {
  const [tokens, setTokens] = useState(getTokenJson({ category: 'colors' }))
  return (
    <div>
      <input onChange={(e) => setTokens(getTokenJson({ category: 'colors', query: e.target.value }))} />
      <div dangerouslySetInnerHTML={{ __html: getTokenHtml({ tokens }) }} />
    </div>
  )
}
```

The same works with Vue's `v-html`, Solid's `innerHTML`, or writing the string to a file.

### `getTokenCss`

Returns your color tokens as CSS variables, keyed to the markup above — the one thing you can't derive from the HTML
alone, since CSS can't read a color out of a `data-` attribute. It ships no layout or design of its own.

```css
/* getTokenCss() output */
[data-value='#ef4444'] {
  --pds-swatch: #ef4444;
}
```

Include it once, then paint a swatch with a single rule of your own:

```css
[data-category='colors'] .pds-token__name::before {
  content: '';
  display: inline-block;
  width: 2.5em;
  height: 2.5em;
  border-radius: 4px;
  background: var(--pds-swatch);
}
```

Everything else — grids, cards, typography, scales — is yours to style off the `data-*` attributes, or skip the HTML
entirely and build your own from `getTokenJson`.
