Studio shows your design system in the browser: every token, which ones your code uses, and every place a raw value was
written instead of a token. Run it in your project:

```bash
pnpm panda studio
```

It opens [studio.panda-css.com](https://studio.panda-css.com/) connected to a local server, and updates as you save.
Nothing from your project is uploaded.

## Tokens

Every token category with a layout that fits it: color swatches, a type specimen, spacing and size scales. Colors with a
`_dark` value show both side by side. Click a token to copy its name, or press `⌘K` to search everything.

If you have more than one [theme](/docs/theming/multiple-themes), pick one from the **Theme** menu to see what it
overrides.

## Usage

**Project scan** shows how many tokens your code uses per category, which ones nothing uses, and every hard-coded value
with the files it's in. Click a file to see its code next to its issues.

**Playground** checks a `css({ ... })` object as you type it and flags any value that isn't a token.

Usage is counted the same way as [`panda analyze`](/docs/design-systems/analyze).

## Options

```bash
pnpm panda studio --port 3001  # default 6420
pnpm panda studio --no-open    # print the link instead of opening a browser
```

See [`panda studio`](/docs/reference/cli#studio) for every flag.

## Without the CLI

Run `panda codegen --spec`, then drop `styled-system/specs/design-system.json` on
[studio.panda-css.com](https://studio.panda-css.com/), or paste a link to it.
