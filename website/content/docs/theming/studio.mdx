# Panda Studio

`panda studio` turns your resolved design tokens into three things you can build on — **data**, **HTML**, and **CSS
variables**. The API is modeled on [Tiptap](https://tiptap.dev)'s `getHTML` / `getJSON`: Panda hands you the content,
you own the presentation. It ships no design of its own.

```bash
panda studio
```

This emits `styled-system/studio` and boots a live viewer at `http://localhost:4000`. Re-run after a config change to
refresh.

## The three functions

`styled-system/studio` exports three framework-agnostic functions:

```ts
import { getTokenJson, getTokenHtml, getTokenCss } from '../styled-system/studio'
```

### `getTokenJson`

Returns your tokens as data. Filter by `category`, search with `query`, or omit both for everything.

```ts
getTokenJson({ category: 'colors' })
getTokenJson({ category: 'spacing', query: 'sm' })
getTokenJson() // all tokens
```

Each token is `{ category, path, name, value, conditions? }`. Semantic tokens include a `conditions` map of their
resolved per-condition and per-theme values. Walk the result to build whatever UI you want.

### `getTokenHtml`

Returns semantic, **style-free** HTML — names and values as text, everything else on `data-*` attributes. It carries no
inline styles and no classes-with-opinions, so it drops into any framework and styles cleanly.

```ts
getTokenHtml({ tokens: getTokenJson({ category: 'colors' }) })
getTokenHtml({ category: 'colors', query: 'brand' }) // filter inline
```

```html
<!-- shape of the output -->
<section class="pds-group" data-category="colors">
  <h2 class="pds-group__title">colors</h2>
  <ul class="pds-tokens">
    <li class="pds-token" data-category="colors" data-name="red.500" data-value="#ef4444">
      <span class="pds-token__name">red.500</span>
      <code class="pds-token__value">#ef4444</code>
    </li>
  </ul>
</section>
```

Drop the string into any framework:

```tsx
// React
function Colors() {
  const [tokens, setTokens] = useState(getTokenJson({ category: 'colors' }))
  return (
    <div>
      <input onChange={(e) => setTokens(getTokenJson({ category: 'colors', query: e.target.value }))} />
      <div dangerouslySetInnerHTML={{ __html: getTokenHtml({ tokens }) }} />
    </div>
  )
}
```

The same works with Vue's `v-html`, Solid's `innerHTML`, or writing the string to a file.

### `getTokenCss`

Takes **your** stylesheet and wires it up. It prepends each token's value as a CSS variable (`--pds-value`) on the
matching `[data-value]` element — the one thing static CSS can't do, since it can't read a value out of a `data-`
attribute — then returns your CSS appended.

```ts
getTokenCss(myStylesheet) // "[data-value=\"#ef4444\"]{--pds-value:#ef4444}…" + myStylesheet
```

So in your own CSS you reference `var(--pds-value)` and it resolves to the token's real value:

```css
/* your stylesheet */
[data-category='colors'] .pds-token__name::before {
  content: '';
  display: block;
  height: 56px;
  border-radius: 6px;
  background: var(--pds-value);
}
```

Include `getTokenCss(yourCss)` once and every color swatch paints itself; the same trick drives spacing bars, aspect
ratios, or animation previews. Values that would break a stylesheet are dropped. Panda never authors the design — the
grid, the cards, the typography are all yours.

## Live viewer

`panda studio` serves a viewer rendered from these same functions. By default it's unstyled markup — pass your own
stylesheet to make it yours:

```bash
panda studio --css ./studio.css        # render the viewer with your stylesheet
panda studio --port 4000
```

`--css` is read and passed straight through `getTokenCss`, so your file can lean on `var(--pds-value)` and the
`pds-*` classes above. It's the same path any consumer takes — Panda's viewer has no private styling.

## Rendering it yourself

You don't need the viewer. Import the three functions and compose them however you document your design system — an app
route, an MDX page, or Storybook. `getTokenJson` for full control, `getTokenHtml` + `getTokenCss(yourCss)` when you want
the markup done for you and only the look to own.
