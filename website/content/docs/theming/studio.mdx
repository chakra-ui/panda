Panda v1 shipped a separate Studio app: install a framework, boot a server, self-host to share. v2 removes it. Instead,
Panda writes your design system to a plain JSON file, and you render it however you like — a page in your app, a
Storybook story, an MDX doc. You own the design; Panda owns the data.

This guide builds a small studio from that file.

## The data

`panda codegen` (or a full `panda` build) writes `styled-system/specs/tokens.json` — a flat snapshot of your tokens
grouped by category:

```json
{
  "data": [
    {
      "type": "colors",
      "values": [{ "name": "red.500", "value": "#ef4444" }]
    }
  ]
}
```

Every category is `{ type, values: [{ name, value }] }`. Values are resolved, so a color is ready to paint and a spacing
value is ready to size a box. See the [JSON Spec](/docs/theming/json-spec) reference for the full file.

## A color grid

Find the `colors` group and map its values into swatches:

```tsx
import { grid } from 'styled-system/patterns'
import tokens from 'styled-system/specs/tokens.json'

export function Colors() {
  const colors = tokens.data.find(group => group.type === 'colors')

  return (
    <div className={grid({ columns: 3, gap: '4', padding: '6' })}>
      {colors?.values.map(color => (
        <div key={color.name}>
          <div
            style={{
              background: color.value,
              height: 64,
              borderRadius: 8,
              border: '1px solid rgba(0,0,0,0.1)'
            }}
          />
          <p>{color.name}</p>
          <p>{color.value}</p>
        </div>
      ))}
    </div>
  )
}
```

## Any category

The same shape works for spacing, radii, fonts — anything in your theme. Swap the category and render what fits it. Here
spacing values size the bar next to each name:

```tsx
import tokens from 'styled-system/specs/tokens.json'

export function Spacing() {
  const spacing = tokens.data.find(group => group.type === 'spacing')

  return (
    <table>
      <tbody>
        {spacing?.values.map(token => (
          <tr key={token.name}>
            <td>{token.name}</td>
            <td>{token.value}</td>
            <td>
              <div style={{ width: token.value, height: 12, background: 'currentColor' }} />
            </td>
          </tr>
        ))}
      </tbody>
    </table>
  )
}
```

## Keep it in sync

The file regenerates on every `panda codegen`, so your studio tracks your config with no extra build to run and nothing
to redeploy. Import it wherever your tokens should be visible — a design-system page, a Storybook story, an MDX doc.
