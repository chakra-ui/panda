# sandbox/prose

Playground for [`@pandacss/preset-typography`](../../packages/preset-typography) — TanStack Router + Vite + the
`prose` recipe.

## Run

```bash
pnpm --filter sandbox-prose install
pnpm --filter sandbox-prose dev
```

Open the app, then try:

- **Size** — SM / MD / LG / XL / 2XL
- **Dark** — toggles the `.dark` class (semantic token `_dark` values)
- **Max width off** — removes the default `sizes.prose` cap
- **/not-prose** — island that opts out of prose styles
